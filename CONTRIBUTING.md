# Contributing to PySCF

See the "How to contribute" section of the PySCF website: https://pyscf.org/contributing.html

If you use an AI coding agent, see [Agent Recipes](agent-recipes/README.md)
for PySCF development guidance, coding conventions, and a PR review checklist.

Before submitting a pull request on GitHub, we recommend checking your changes
and PR description with the [PR review template](agent-recipes/skills/pyscf-pr-review.template.md).
Use it as a manual checklist or ask your coding agent to apply it.
